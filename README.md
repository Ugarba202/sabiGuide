# SabiGuide

AI-powered student navigation platform helping Nigerian students move from WAEC to NYSC through admissions, scholarships, NELFUND guidance, and career opportunities.

## Vision

No student should miss an educational opportunity because of lack of information.

## MVP

- WAEC Guidance
- JAMB Guidance
- Post UTME Guidance
- NELFUND Guidance
- Scholarship Discovery
- WhatsApp Assistant

## Tech Stack

- Flutter
- NestJS
- Supabase & PostgreSQL
- Gemini
- WhatsApp Cloud API
